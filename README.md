# Projet 2 - Acquisition d'instruments

## Description

Application Python permettant de piloter un multimètre (réel ou simulé), d'acquérir des mesures et de les afficher dans une interface graphique.

## Technologies

- Python
- PySide6
- PyVISA
- Programmation orientée objet
